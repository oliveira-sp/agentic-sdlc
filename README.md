# Agentic SDLC

An open-source framework for orchestrating AI agents across the software development lifecycle.

## Vision

Agentic SDLC aims to provide a structured way to integrate AI agents into software engineering workflows.

Instead of using AI only as a coding assistant, this project explores how specialized agents can collaborate through:

- defined workflows
- engineering artifacts
- human approval checkpoints
- reproducible processes

## Core Principles

### Workflow-driven

AI agents operate within explicit workflows rather than unstructured conversations.

### Artifact-driven

Agents communicate through durable engineering artifacts such as:

- requirements
- architecture documents
- implementation plans
- review reports

### Specialized agents

Each agent has a focused responsibility.

Examples:

- Product Manager Agent
- Engineering Planner Agent
- Coder Agent
- Review Agent

### Human-controlled

Important decisions remain under developer control.

Examples:

- requirement approval
- architecture decisions
- implementation batches
- commits
- merge requests

## Planned Workflows

### Product Workflow

Transform ideas into structured engineering requirements and GitLab issues.

### Engineering Workflow

Transform issues into implementation-ready plans.

### Implementation Workflow

Execute development batches with validation steps.

### Review Workflow

Validate changes and prepare merge requests.
